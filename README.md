# Submission Instructions

## Important Notice:
Due to file size limitations, it was unable to upload the complete datasets in one submission. 


## Setup Instructions:
1. **Upload the datasets**  
   - Ensure that both `srm_full.parquet` and `solr_class_data_13.09.parquet` are placed inside the `/data` directory.

2. **Run Preprocessing Code**  
   - Before running any analysis, execute the **preprocessing script** first.  
   - The preprocessing step will **generate all necessary data** for the matched and non-matched data analysis code.

3. **Proceed with Analysis**  
   - Once preprocessing is complete, you can run the matched and non-matched data analysis scripts.
